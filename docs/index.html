Gate 1 · STOP AND ASK

Sentimento e Opinião antes do código

O agente para tudo e faz 4 perguntas secas para impedir o padrão genérico de SaaS:

  • Emoção em 3 adjetivos: ex. humano, manual, rasurado.
  • Superfície e material: papel creme, nanquim, jornal, vidro fosco.
  • Paleta travada: no máximo 2 neutros e 1 cor de destaque intencional.
  • Tipografia com caráter: serif editorial para leitura e manuscrito nas margens.

Teste de direção (clique para montar o DESIGN_SPEC):

DESIGN_SPEC: Papel #F2EBDD + Grafite #292821 + Rasura #A64B3C
Gate 2 · STOP AND WAIT

Caça real de referências

Antes de pedir código, você traz 2 ou 3 referências visuais concretas de acervos reais:

  • Mood e texturas físicas: are.na, cosmos.so, savee.it.
  • Tipografia e personalidade: godly.website, siteinspire.com, curated.design.
  • Fluxos e UX limpa: mobbin.com, refero.design.
  • Micro-interações de desenho: tympanus.net/codrops, lottiefiles.com.

O agente extrai tokens exatos (cores hex, ritmo de espaçamento, curvas de easing) para o DESIGN_SPEC.

Gate 3 · STOP AND CONFIRM

Esboço na mão ou mapa ASCII

Você envia a foto de um rascunho feito no caderno ou aprova um mapa estrutural em ASCII adaptado ao Gate 1 e 2.

  • Nenhuma pasta src/ ou arquivo HTML nasce antes do seu "OK".
  • Define tensão de layout, proporção de margens e hierarquia real do conteúdo.
  • Evita seções vazias ou preenchimento de template que ninguém pediu.
Gate 4 · BESPOKE ASSETS

Aquarela p5.brush e Lottie vivo

Quando o projeto pede arte orgânica ou movimento vetorial, ícones genéricos ficam de fora:

  • Arte orgânica e papel: invoca watercolor-obj ou watercolor-obj-p5 (morikyl/skills).
  • Animação vetorial: usa @lottiefiles/creator-mcp para gerar e editar Lottie JSON em tempo real.
  • Nanquim autoral: ilustrações em traço irregular com personalidade própria.
Gate 5 · ANTI-SLOP AUDIT

Iteração intencional e rasura

O primeiro rascunho nunca é o final. O agente executa duas checagens explícitas após renderizar:

  • Tipografia e movimento: contraste WCAG AA, easing não-linear e foco visível no teclado.
  • Auditoria Anti-Slop: risca gradientes roxos genéricos, grids de cards idênticos, estatísticas inventadas e botões mortos.

Instalação na sua máquina

zero gasto de token para plugar

1. Instalar a skill + aquarela p5.brush

Instale a human-craft-frontend e os extras orgânicos do morikyl/skills direto no terminal:

npx skills add santanaluiz181-cell/human-craft-frontend
npx skills@latest add morikyl/skills --skill watercolor-obj watercolor-obj-p5

2. Plugar LottieFiles Creator no mcp_config.json

Adicione o servidor MCP abaixo no seu mcp_config.json do Antigravity para gerar vetores animados ao vivo:

{
  "mcpServers": {
    "lottiefiles-creator": {
      "command": "npx",
      "args": ["-y", "@lottiefiles/creator-mcp@latest"]
    }
  }
}
